# Birthday Balloon Game

A beautiful, interactive birthday website with a balloon popping game and editable content protected by a 4-digit code.

## Features

- Interactive balloon popping game with hidden messages
- Editable content (name, messages, photos, etc.)
- 4-digit code protection for editing
- Confetti animations
- Mobile-friendly design
- Music player integration

## How to Use

1. Open `index.html` in a web browser
2. Click the lock button (🔒) at the bottom
3. Enter the 4-digit code "1234" to unlock editing
4. Customize the content as desired
5. Share with the birthday person!

## Hosting

This site can be hosted on any web server or GitHub Pages.
